# Planning artifacts

ETHGlobal's rules ask spec-driven teams to commit their specs, prompts and planning. This folder holds them.

- `decisions.md`: every product and design decision, dated, with who made it.
- `prompts.md`: the team's prompts to the AI coding assistant, in order and in their own words. Secrets that appeared in them (a burner wallet key, API keys) are replaced with `[redacted]`.
- `../business.md`: market, starter, funnel and unit economics, written from a conversation with a builder at the event.
- `../../TASKS.md`: the task list we worked from.
- `../../video/STORYLINES.md`, `SCRIPT.md`, `SPEC.md`: the explainer film's plan.

How we worked: the team decided what Daak does, for whom, and how each part should behave (the prompts and decisions show this); an AI coding assistant wrote most of the code to those decisions, and `AI_USAGE.md` lists that file by file. Every feature was checked against the real thing: testnet transactions, the phone, the browser.
